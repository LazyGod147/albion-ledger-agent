# Агенты

В проекте два способа доставлять данные на сайт. Выбор зависит от того,
хотите вы автоматический захват или ручную/полуавтоматическую загрузку.

## sniffer_agent.py — снифер (то, чем вы пользовались раньше)

Висит в трее, читает сетевой трафик игры, сам разбирает рыночные сделки и
шлёт их на сайт под вашим токеном. Это аналог albiondata-client, только
данные идут к вам, а не в общий пул. **Покупки и продажи ловятся
автоматически.**

Требуется:

    pip install scapy photon-packet-parser requests
    pip install pystray Pillow          # по желанию — иконка в трее

Плюс **Npcap** — тот же драйвер захвата, что вы ставили для прошлой
программы. Скачивается с npcap.com, галочку «WinPcap API-compatible mode»
при установке оставьте включённой.

Настройка:

    copy sniffer_config.sample.json sniffer_config.json    # Windows
    cp   sniffer_config.sample.json sniffer_config.json    # Linux/macOS

Впишите site_url и token (токен выпускается на сайте, «Настройки»).
character можно оставить пустым — агент возьмёт имя из пакетов.

Запуск — обязательно от администратора, захват трафика требует прав:

    python sniffer_agent.py               # обычная работа, висит в трее
    python sniffer_agent.py --no-tray     # то же, но без иконки
    python sniffer_agent.py --list-ifaces # показать сетевые интерфейсы

При старте агент проверяет токен на сайте и, если тот не принят, не
запускается. Дальше держите окно (или трей) открытым во время игры.

### Автозапуск в Windows

Захват требует прав администратора, поэтому обычный ярлык в автозагрузке
не подойдёт — нужен «Планировщик заданий»: задача «при входе в систему»,
галочка «Выполнять с наивысшими правами», действие — запуск pythonw.exe с
аргументом sniffer_agent.py.

### Если сделки перестали ловиться после патча

Это ожидаемо: игра меняет коды операций почти каждое обновление. Лечится
без правки кода.

    python sniffer_agent.py --discover

Проведите в игре одну покупку или продажу и смотрите вывод — агент
напечатает все прошедшие операции с их кодами и параметрами. Найдите
строку, где видны id предмета, количество и цена, и впишите её код в
sniffer_config.json → operation_codes. Если сместились индексы полей
внутри параметров — поправьте field_map. Числа справа — единственное, что
меняется.

### Чего снифер не ловит

Крафт. Готового разбора событий производства нет ни в одном открытом
клиенте, и делать его пришлось бы с нуля с поломкой на каждом патче.
Крафт вносится через сайт (раздел «Крафт») или кладётся в папку для
agent.py — это редкое событие, пары кликов на партию достаточно.

## agent.py — загрузчик из папки

Не снифер. Следит за папкой и отправляет на сайт всё, что в неё положат —
CSV или JSON в формате из docs/EVENTS.md. Нужен для того, что снифер не
покрывает: крафтовые партии из таблицы, историю из стороннего трекера,
ручные выгрузки за прошлые месяцы. Зависимостей нет, нужен Python 3.9+.

    cp config.sample.json config.json
    python agent.py --ping
    python agent.py

## Можно ли так вообще делать

Пассивный захват трафика Sandbox Interactive допускает: их технический
директор публично говорил, что смотреть и анализировать трафик можно, а
менять или вмешиваться в работу игры — нет. На этом живут все
перечисленные открытые клиенты. Снифер только читает пакеты: не трогает
память игры, не меняет файлы и ничего не делает за вас в игре. Эту грань
важно не переходить.
